## 操作

| 口令 | 行为 |
| --- | --- |
| 拍照 | 核验拍照前置参数回显，切换照片模式，再发送原生拍照；原生任务进行中需先停止 |
| 开始录像 | 切换视频模式，再开始原生录像 |
| 停止录像 | 请求结束录像、保存机内文件；暂停语音时仍可在键盘输入 |
| 相册 / 媒体列表 | 从飞机读取实时媒体目录，显示最新项目 |
| 下载最新照片 / 下载照片 | 重新读取目录，下载最新照片原片到 PC |
| 下载最新录像 / 下载录像 | 重新读取目录，下载最新已停止的录像原片到 PC |

原片保存位置：

```text
开发基地1\captures\pc-downloads\
```

建议先说 `拍照`，等拍照回复及文件保存后说 `下载最新照片`。再说 `开始录像`，录约 5–10 秒，说 `停止录像`，等状态更新后说 `下载最新录像`。

程序不会把 `00` 回复当成文件已保存的证明。下载会核对实时目录的文件名和大小、HTTP 长度和分段范围，并检查 JPEG 解码或 MP4 文件结构后才发布最终文件。缺失、不完整、大小未知的文件会报错；不会用旧文件冒充最新文件，也不会覆盖同名原片。重复下载时可直接打开已经保存的文件。

相机状态未知或仍在录像时，不切换拍照模式；录像需先停止再下载最新录像。“停止”会取消当前操作并回中飞行控制，“停止录像”是单独结束录像。下载过程中“降落”仍走原来的降落入口。
