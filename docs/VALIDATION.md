# 验证范围与交接边界

## 精简原则

基于完整版本 `cf8ccf7` 提取，保留协议编码、控制会话和状态检查。初版精简之后，按需求补回视频解码/预览、离线语音、相机控制与原片下载；分为通信核心与可选电脑扩展。仍不分发原始抓包和媒体，移除了必须依赖这些私有样本的历史回放用例。测试使用内嵌报文字面量、注册/环绕 profile 和本机模拟。

模块改名及来源见 `SOURCE_MAP.json`。`flight_controller.py` 仍保留完整的接收/发送循环、取消边界、路由序号、起降与环绕接续检查；不只是截取一个起飞字节。

## 自动验证入口

```powershell
python -S run_tests.py
```

扩展回归入口：

```powershell
python -m pip install -r requirements-extras.txt
python run_tests.py --extras
```

2026-11-02 扩展实际执行结果：**227 项测试全部通过，无跳过**（Windows / Python 3.12，已有 PyAV/Pillow 环境）。基础测试使用 `-S` 验证不依赖第三方包；新增的相机协议和 channel-3 数据流用例也在基础组内。

基础组只依赖 Python 标准库，扩展组需要可选依赖；没有执行新的真机连接、起飞、降落、拍摄或下载。`samples/golden-vectors.json` 为确定性跨语言比对数据，另有用例保留独立抓包字面量断言。固定样本中的 session、seq、counter 仅用于离线测试，不应直接作为实际会话常量。

覆盖范围包括：外层长度/XOR、DUML CRC、错误 session/回复序号拒绝、启动注册、可靠累计确认与重传、路由状态跨重启、动作回中和取消、降落优先、旧状态隔离、落地重飞、半径回读、原生停止与接管、视频分片重复/冲突/过期。
