# 验证范围与交接边界

## 精简原则

基于完整版本 `cf8ccf7` 提取，保留协议编码、控制会话和状态检查。去掉电脑 CLI、语音、相机控制、媒体下载及它们的用例；去掉必须依赖不分发的原始抓包的历史回归用例。现存核心用例不因缺抓包而跳过，使用内嵌报文字面量、注册/环绕 profile 和本机 UDP 模拟。

模块改名及来源见 `SOURCE_MAP.json`。`flight_controller.py` 仍保留完整的接收/发送循环、取消边界、路由序号、起降与环绕接续检查；不只是截取一个起飞字节。

## 自动验证入口

```powershell
python -S run_tests.py
```

2026-11-02 实际执行结果：**128 项测试全部通过，无跳过**（Windows / Python 3.12，禁用 site-packages）。

只依赖 Python 标准库；没有执行新的真机连接、起飞或降落。`samples/golden-vectors.json` 为确定性跨语言比对数据，另有用例保留独立抓包字面量断言。固定样本中的 session、seq、counter 仅用于离线测试，不应直接作为实际会话常量。

覆盖范围包括：外层长度/XOR、DUML CRC、错误 session/回复序号拒绝、启动注册、可靠累计确认与重传、路由状态跨重启、动作回中和取消、降落优先、旧状态隔离、落地重飞、半径回读、原生停止与接管、视频分片重复/冲突/过期。
