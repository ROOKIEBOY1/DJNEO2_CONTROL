# 智能滑动变焦 PC 使用说明

独立键盘入口，复用现有可靠连接、持久路由序号与图传。可设置半身/全身/远景，倍率1–2×或1–3×，变焦前渐远开/关；相机使用录像模式。主体由飞机自动识别，PC可查看检测框及跟踪框信息。另已接入 voice_console.py 离线语音入口，详见《智能滑动变焦语音使用说明.md》；当前不提供独立持续跟随。

## 连接前

先让飞机落地，退出其他电脑控制台、断开手机 DJI Fly 的飞机连接，再让电脑连接飞机 Wi-Fi。电脑不需要互联网。首次PC实测应在安全空旷处，让相机能看到人物。

在项目根目录运行：

```powershell
python .\extras\dolly_zoom_console.py --connect --video
```

浏览器打开程序打印的 `http://127.0.0.1:端口/` 地址看实时视频。不需要图传窗口可去掉 `--video`；链路仍会核验收到的新鲜视频数据。不带 `--connect` 只显示离线说明，不连接飞机。

## 首次验证

默认配置为半身、1–2×、渐远开、录像，无需再输入设置：

```text
准备
```

等待“准备完成”。这一步先按手机流程清理旧任务，再设置任务模式/参数、校时并确认相机录像模式；不启动任务，也不单独开始录像。程序逐项核验成功回复、参数回显、相机状态及飞机落地状态，任何一步未通过都不继续启动。

然后输入：

```text
滑动变焦
确认
```

确认需在10秒内输入。任务可能自动起飞。启动回复00表示请求被接受，不能单凭它认定飞机已经执行、主体已经锁定或文件已保存；请观察飞机及任务状态。

首次明显执行几秒后输入：

```text
停止
```

目视确认悬停后输入：

```text
降落
```

确认实际落地后输入 `退出`。首次版本每次连接只发起一轮任务；需要再次执行时，落地后退出并重开程序。不要同时打开语音控制台、环绕控制台或手机连接来控制飞机。

## 修改参数

在“准备”之前输入，例如：

```text
景别 全身
倍率 3
渐远 关
准备
```

修改设置会取消待确认请求，并要求重新准备。倍率仅支持2或3，表示1–2×/1–3×；不是飞行距离。不接受超出本机抓包证据的值。

## 查看状态与主体

- `状态`：任务配置、连接、相机、飞行及视觉状态。
- `主体`：终端显示候选目标ID、原始状态和归一化框坐标。图传窗口现已叠加飞机回传的框：绿框为跟踪框，黄框为候选主体。框数据或显示画面过期时清除，框本身不作为已锁定的证明。普通模式下若飞机没有回传识别结果，PC不会凭空生成框。
- `停止`：取消尚在准备/启动的操作并请求停止原生任务；停止后预期悬停，降落需另行输入。
- `降落`：先尝试停止原生任务，即使停止请求失败仍请求降落。
- `退出`：取消本地操作；若本轮可能已启动，会尝试停止任务和降落。仍需目视确认落地。

任务阶段 `050d000100` 表示本机观察到的执行阶段；`0000000101/02` 为本次结束/停止后出现的状态。候选框不单独证明主体锁定；通信过期不会保留旧框当成新检测结果。

## 录像与记录

原生任务负责拍摄，程序不会额外发送独立开始录像命令。录像是否保存需在飞机相册核实。落地并退出本控制台后，可用原有语音控制台的“相册”“下载最新录像”下载原片到PC。

退出时会打印 `captures/control-attempt-*.json` 路径，包含任务请求、回显和视觉/相机状态。操作者已确认PC滑动变焦执行成功；后续新增的图传叠加与诊断改动仍需实测，本机测试不替代实际飞行观察。
