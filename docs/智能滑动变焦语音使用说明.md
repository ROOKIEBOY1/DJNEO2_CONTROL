# 智能滑动变焦离线语音

沿用已经验证的 PC 原生滑动变焦流程，现接入离线中文语音控制。默认半身、1–2倍、变焦前渐远开、录像。当前只从地面启动，由飞机自动识别主体。

## 开始

飞机保持落地；退出独立滑动变焦控制台、其他电脑控制台和手机 DJI Fly 的飞机连接。电脑连接飞机 Wi-Fi 后，在项目根目录运行：

```powershell
python .\extras\voice_console.py --connect --video
```

浏览器打开程序打印的本地预览地址。键盘输入一次：

```text
启用语音
```

然后说：

```text
滑动变焦
确认
```

“确认”须在10秒内说出，表示目视确认已落地并启动本次任务。程序自动完成旧任务清理、参数设置及完整回显核对、相机校时和录像模式核验，然后发起任务；无需另说起飞、准备或开始录像。启动回复00仍需结合任务状态及实际飞行观察。

## 参数口令

在启动前可逐条说，例如：

```text
景别全身
倍率三倍
渐远关闭
滑动变焦
确认
```

| 功能 | 支持口令 |
| --- | --- |
| 景别 | 景别半身 / 景别全身 / 景别远景 |
| 变焦范围 | 倍率两倍 / 倍率三倍，对应1–2× / 1–3× |
| 变焦前渐远 | 渐远开启 / 渐远关闭 |
| 仅准备参数 | 准备滑动变焦，不发起任务 |
| 启动 | 滑动变焦 → 确认 |
| 停止并预期悬停 | 停止滑动变焦 / 停止 |
| 请求降落 | 降落 |
| 查看 | 状态 |

修改参数会取消尚未确认的启动请求。任务进行中不接受方向动作、环绕切换或新的相机操作；可先停止任务，再等待飞机回报允许接续的状态。滑动变焦本轮启动仍要求地面；不能通过说“起飞”再在空中启动。

停止后请观察是否悬停，降落需单独说出。确认落地后，可再次说“滑动变焦→确认”，程序会核对新鲜落地状态并开始新一轮；也可接续原有起飞或环绕流程。若状态缺失、过期或旧任务未结束，程序会拒绝启动。

2026-11-02 根据手机成功降落补采，语音入口已补上后续降落阶段。仍只说一次“降落”：任务已明确结束时不重复发送任务停止；初始降落请求成功后，只有持续收到抓包匹配的近地降落状态才自动发送一次后续指令。若恢复悬停或遥测过期，不补发；“停止”“暂停语音”“退出”会取消尚未发送的后续阶段。此修改尚需PC实测，回复00始终不等于落地。

语音和键盘使用相同口令。键盘“降落”在暂停语音时仍有效；“停止”“停止滑动变焦”会取消待确认及正在准备的启动操作。低置信度或过期口令仍按原有策略忽略。

## 图传、录像与日志

图传沿用主体框叠加及视频诊断。任务执行状态和候选主体数量会打印到控制台；框不是独立跟随或锁定成功的证明。原生任务负责录像，完成后可用“相册”“下载最新录像”核验并保存原片。

退出时保存 `captures/control-attempt-*.json` 和 `captures/voice-session-*.json`。本轮没有自动向飞机发送指令；语音调度、原有控制功能和本机离线识别语法已验证，首次语音实飞仍请反馈实际表现。
